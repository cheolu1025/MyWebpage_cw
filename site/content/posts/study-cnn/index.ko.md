## 왜 CNN이 필요했나

이미지를 MLP에 넣으려면 2차원 이미지를 한 줄로 펼쳐야 합니다.
이 과정에서 픽셀 사이의 위치 관계가 사라지고, 입력 크기만큼 가중치가 늘어나 계산도 비효율적이 됩니다.
CNN은 이미지를 2차원 구조 그대로 다루고, 작은 필터 하나를 이미지 전체에 공유해서 이 문제를 풀었습니다.
덕분에 파라미터 수는 줄고, 물체의 위치가 조금 바뀌어도 같은 특징을 잡아낼 수 있습니다.

## CNN을 이루는 요소

- Convolution: 학습 가능한 작은 가중치 행렬(kernel)이 이미지 위를 이동하며 지역 특징을 뽑아 feature map을 만듭니다.
- Stride와 Padding: stride는 필터가 한 번에 이동하는 칸 수로, 클수록 출력 크기와 연산량이 줄어듭니다. padding은 가장자리에 값을 덧대어 출력 크기를 조절하고 테두리 정보를 지킵니다.
- Receptive Field: 출력 뉴런 하나가 보는 입력 영역의 크기입니다. 작으면 선이나 모서리 같은 세부 특징을, 크면 얼굴이나 물체 전체 같은 큰 구조를 봅니다.
- Pooling: feature map의 작은 영역을 대표값 하나로 요약합니다. 크기는 줄이면서 층이 깊어질수록 receptive field를 효과적으로 넓혀 줍니다.

## ResNet: 깊어질수록 학습이 어려워지는 문제

네트워크를 깊게 쌓으면 성능이 오를 것 같지만, 실제로는 너무 깊어지면 오히려 학습이 잘 되지 않는 문제가 생겼습니다.
ResNet은 층이 원하는 출력 H(x)를 직접 배우는 대신, 입력과의 차이 F(x)만 배우고 입력 x를 shortcut으로 그대로 더해 줍니다.
이 shortcut 경로로 gradient가 앞쪽 층까지 직접 전달되기 때문에, 깊은 네트워크에서도 gradient가 사라지는 문제가 완화됩니다.

## U-Net: 위치까지 정확하게 복원하기

U-Net은 이미지를 줄여 가며 맥락을 파악하는 encoder와, 다시 키워 가며 위치를 복원하는 decoder로 이루어진 구조입니다.
encoder의 세부 위치 정보를 decoder로 바로 넘겨 주는 skip connection 덕분에, 픽셀 단위로 정확한 분할 결과를 얻을 수 있습니다.
의료 영상처럼 데이터가 적은 분야를 위해 큰 이미지를 겹치는 타일로 나눠 처리하고, 이미지를 비틀어 새 학습 데이터를 만드는 데이터 증강도 함께 사용한 점이 인상 깊었습니다.

## CNN과 ViT

CNN은 필터로 가까운 영역부터 특징을 쌓아 올리기 때문에 적은 데이터에서도 비교적 잘 학습되지만, 멀리 떨어진 영역 사이의 관계를 직접 보기는 어렵습니다.
ViT는 이미지를 패치로 잘라 토큰처럼 다루고 attention으로 패치 전체의 관계를 한 번에 학습해, 넓은 문맥을 잘 보는 대신 많은 데이터와 연산이 필요합니다.
이 비교가 이후 Swin Transformer와 ConvNeXt를 공부하게 된 계기가 되었습니다.

## 정리하며

이번 공부로 이후 읽은 논문들의 기본 단위를 익혔습니다.
특히 ResNet의 residual connection은 이후 공부한 모델들에서도 기존 정보를 보존하는 장치로 계속 등장했고, U-Net에서 본 데이터 증강의 필요성은 지금 연구에서 과적합을 줄이기 위해 고민하는 부분과도 바로 이어졌습니다.
