학부연구생으로 참여하고 있는 이벤트 카메라(DVS) 영상 기반 이상 행동 탐지 연구를 정리한 글입니다.

<!--more-->

## 개요

- 기간: 2026년 8월 ~ 현재 (진행 중)
- 형태: 학부연구생, 연구실 연구
- 분야: 이벤트 기반 비전(Event-based Vision), 영상 이상 행동 탐지(Video Anomaly Detection)
- 사용 도구: Python, PyTorch, Docker

## 연구 배경과 목표

이 연구는 UCF-Crime-DVS 데이터셋을 사용합니다.
UCF-Crime-DVS는 CCTV 범죄 영상 데이터셋인 UCF-Crime을 이벤트 카메라 형식으로 변환한 데이터셋으로, 이벤트 데이터를 이용한 이상 행동 탐지 벤치마크로 공개되었습니다.
([Qian et al., 2025, arXiv:2503.12905](https://arxiv.org/abs/2503.12905))

이벤트 카메라는 일반 카메라처럼 일정 간격으로 전체 화면을 찍지 않고, 픽셀마다 밝기가 변할 때만 신호(이벤트)를 기록합니다.
그래서 움직임에는 민감하고, 변화가 없는 배경은 거의 기록하지 않는다는 특징이 있습니다.

데이터를 분석해 보니, 실제 이상 행동이 일어나는 구간은 대체로 이벤트가 더 많이 발생했습니다.
하지만 정상적인 장면이라도 사람이 많이 움직이면 이벤트가 크게 늘어나기 때문에, 이벤트 양만 보고 판단하면 정상 구간을 이상으로 잘못 탐지하는 경우가 생겼습니다.

그래서 이 연구의 목표를 "이벤트가 많다는 것만으로 이상은 아니다"를 모델이 구분하도록 만드는 것으로 잡았습니다.
즉, 이상 행동을 찾아내는 능력은 유지하면서, 움직임이 많은 정상 구간에서 생기는 오탐(False Alarm)을 줄이는 것이 목표입니다.

## 수행 과정

아래 과정은 교수님의 피드백을 받아 방향을 정한 뒤, 코드 분석부터 실험과 결과 정리까지 모두 제가 직접 진행했습니다.

### 1. 기존 코드 분석과 단순한 기준 모델 만들기

먼저 공개된 UCF-Crime-DVS 코드를 읽으며 데이터 샘플링, 모델 구조, 손실 함수가 어떻게 이어지는지 파악했습니다.
원래 모델에는 여러 복잡한 모듈이 겹쳐 있었는데, 이 상태에서 새 아이디어를 더하면 성능 변화가 어디서 왔는지 알기 어렵다고 판단했습니다.
그래서 복잡한 모듈을 걷어 낸 단순한 기준 모델(baseline)을 먼저 만들고, 이후 모든 시도를 이 모델과 비교하는 방식으로 실험을 설계했습니다.

### 2. 이벤트 양 분석

다음으로 영상의 시간 구간마다 발생한 이벤트 수를 직접 계산해, 정상 영상, 이상 영상 속 정상 구간, 실제 이상 구간의 분포를 비교했습니다.
이벤트 양만으로도 이상 구간을 어느 정도 구분할 수 있다는 것을 확인했고, 이를 모델의 보조 정보로 써 볼 가치가 있다고 보았습니다.
이 과정에서 한 영상의 특징 길이와 이벤트 길이가 맞지 않는 데이터 문제를 발견해, 해당 샘플을 제외한 학습 목록을 따로 만들었습니다.

### 3. 이벤트 통계 설계와 결합 실험

이벤트 수를 그대로 넣기보다, 의미가 다른 세 가지 통계로 나누어 설계했습니다.
전체 데이터 기준으로 지금 이벤트가 얼마나 많은지, 직전 순간보다 얼마나 변했는지, 그리고 이 영상의 최근 평소 상태와 비교해 얼마나 튀는지입니다.
이 통계들을 기존 특징에 붙이거나 특징의 크기를 조절하는 방식 등으로 여러 조합을 실험했고, 그중 최근 상태 대비 변화량이 이상 구간을 가장 잘 구분한다는 것을 확인했습니다.

### 4. 오탐 문제와 Hard Normal Mining

이벤트 정보를 강조하자 이상 행동은 더 잘 찾았지만, 움직임이 많은 정상 구간까지 이상으로 판단하는 오탐도 함께 늘었습니다.
이를 줄이기 위해 Hard Normal Mining을 적용했습니다.
정상 영상 가운데 모델이 이상으로 착각하기 쉬운 구간을 골라 추가로 학습시키고, 이벤트가 갑자기 튀는 구간일수록 더 강하게 바로잡도록 구성했습니다.

### 5. 결과를 판단한 기준

실험 중에는 숫자만 보면 좋아 보이는 결과도 있었습니다.
예를 들어 특정 손실 가중치를 크게 키우자 오탐률이 크게 줄었는데, 점수 분포를 직접 확인해 보니 정상과 이상이 더 잘 나뉜 것이 아니라 모든 점수가 판정 기준 아래로 몰려 있었을 뿐이었습니다.
그래서 이 설정은 채택하지 않았고, 이후에는 한 번의 최고 점수보다 학습 곡선 전체와 점수 분포를 함께 보고 대표 결과를 고르는 기준을 세웠습니다.
