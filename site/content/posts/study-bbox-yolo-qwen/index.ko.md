DVS 연구에서 비전-언어 모델이 찾은 객체 위치를 활용할 수 있을지 판단하기 위해, 객체 탐지 모델 YOLO와 바운딩 박스 정확도를 직접 비교해 본 실험입니다.

<!--more-->

## 실험 개요

- 시기: 2026년 9월 초
- 목적: DVS 연구에 사용하는 AI 도구인 Qwen2.5-VL이 YOLO만큼 정확한 바운딩 박스를 낼 수 있는지 확인하고, 연구에서 바운딩 박스 정보를 사용할 수 있을지 판단하기
- 데이터: COCO 데이터셋 이미지와 정답 바운딩 박스(GT)
- 비교 대상
  - YOLO: 객체 탐지 전용 모델
  - Qwen Basic: Qwen2.5-VL-7B에 기본 요청만 준 경우
  - Qwen DVS: 같은 모델에 DVS 연구용으로 직접 설계한 프롬프트를 적용한 경우 (프롬프트 내용은 연구 중이라 공개하지 않습니다)
- 평가 지표: 예측한 박스 수, 그리고 정답 박스와 얼마나 겹치는지를 나타내는 IoU의 평균(Mean IoU)

## 비교 방법

같은 이미지에 대해 세 방법이 예측한 바운딩 박스를 COCO 정답 박스와 짝지어 IoU를 계산하고, 결과를 이미지별로 나란히 시각화해 비교했습니다.
여러 장의 이미지로 비교했고, 아래는 그중 성격이 다른 두 예시입니다.
그림에서 초록색은 정답 박스, 빨간색은 각 방법이 예측한 박스입니다.

## 예시 1: 사람 3명

![COCO 정답, YOLO, Qwen Basic, Qwen DVS의 사람 바운딩 박스를 나란히 비교한 그림. 세 방법 모두 3명을 찾았고 Mean IoU는 각각 0.8493, 0.9091, 0.9184](bbox-example-person.webp "예시 1: 사람 3명 (COCO 이미지 000000119445)")

| 방법 | 예측 수 / 정답 수 | Mean IoU |
| --- | --- | --- |
| YOLO | 3 / 3 | 0.8493 |
| Qwen Basic | 3 / 3 | 0.9091 |
| Qwen DVS | 3 / 3 | 0.9184 |

크고 뚜렷한 사람 객체에서는 세 방법 모두 3명을 빠짐없이 찾았고, 이 예시에서는 Qwen 쪽 박스가 정답과 더 잘 겹쳤습니다.

## 예시 2: 작은 차량 2대

![COCO 정답, YOLO, Qwen Basic, Qwen DVS의 차량 바운딩 박스를 비교한 그림. YOLO는 2대를 찾아 Mean IoU 0.437, Qwen Basic은 1대만 찾아 0.421, Qwen DVS는 2대를 찾아 0.551](bbox-example-vehicle.webp "예시 2: 창밖의 작은 차량 2대 (COCO 이미지)")

| 방법 | 예측 수 / 정답 수 | Mean IoU |
| --- | --- | --- |
| YOLO | 2 / 2 | 0.437 |
| Qwen Basic | 1 / 2 | 0.421 |
| Qwen DVS | 2 / 2 | 0.551 |

창밖에 일부만 보이는 작은 차량은 세 방법 모두 IoU가 크게 낮아졌습니다.
기본 요청만 준 Qwen은 차량 하나를 놓쳤지만, 프롬프트를 적용한 경우에는 두 대를 모두 찾았습니다.

## 정리하며

이 실험을 통해 비전-언어 모델도 상황에 따라 탐지 전용 모델에 가까운 바운딩 박스를 낼 수 있고, 같은 모델이라도 프롬프트 설계에 따라 결과가 달라진다는 것을 직접 확인했습니다.
동시에 작거나 일부만 보이는 객체에서는 어떤 방법이든 정확도가 크게 떨어진다는 점도 보았습니다.
위 두 장은 대표 예시일 뿐이라 일반적인 결론으로 보기는 어렵고, 연구에 바운딩 박스를 활용할지는 여러 장의 결과를 함께 보고 판단해야 한다는 점을 기준으로 삼았습니다.

## 이미지 출처

- 예시 이미지와 정답 바운딩 박스: [COCO 데이터셋](https://cocodataset.org/) (Lin et al., "Microsoft COCO: Common Objects in Context," ECCV 2014)
- 비교 시각화: 직접 실험해 만든 결과 이미지
