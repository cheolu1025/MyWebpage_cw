## 소개

안녕하세요, Cheolwoo Park입니다.

전북대학교 컴퓨터인공지능학부에서 공부하고 있으며, 컴퓨터비전(Computer Vision) 분야에 관심을 두고 있습니다.
현재는 학부연구생으로 연구실에서 이벤트 카메라(DVS) 영상을 활용한 영상 이상 행동 탐지(Video Anomaly Detection) 연구에 참여하고 있습니다.

## 관심 분야

인공지능의 여러 분야를 공부하던 중, 이미지와 영상 속 정보를 분석하고 이해하는 컴퓨터비전(Computer Vision)에 특히 흥미를 느끼게 되었습니다.

사람에게는 한눈에 들어오는 장면도 컴퓨터에게는 수많은 픽셀 값의 나열일 뿐입니다.
그런데 모델이 이 숫자들로부터 객체의 특징과 움직임, 나아가 상황의 의미까지 학습해 낸다는 점이 인상 깊었습니다.
눈으로 보는 정보를 바탕으로 실제 문제를 풀어낼 수 있다는 가능성이 이 분야에 관심을 갖게 된 계기입니다.

이후 CNN, Vision Transformer(ViT), CLIP 같은 모델과 관련 논문을 공부하며, 이미지에서 특징을 추출하고 시각 정보를 학습하는 다양한 접근 방식을 익혀 가고 있습니다.

현재는 학부연구생으로 연구실에 참여해, 이벤트 기반 영상 데이터셋인 UCF-Crime-DVS를 활용한 영상 이상 행동 탐지(Video Anomaly Detection)를 연구하고 있습니다.
논문과 모델 구조를 직접 분석하고 실험하면서, 공부한 이론이 실제 환경에서 어떻게 쓰이는지 하나씩 확인해 가고 있습니다.

## 사용 기술과 경험

- Docker: 연구 서버의 실험 환경을 컨테이너로 실행하고 접속해 작업합니다.
- Python · PyTorch · NumPy: PyTorch 기반 이상 행동 탐지 코드로 학습과 평가를 실행하고, 결과 지표를 NumPy로 정리해 비교합니다.
- Git · GitHub: 연구에 사용하는 원본 코드를 내려받아 관리하고, 이 사이트도 Git으로 버전을 관리하며 GitHub Actions로 배포합니다.

처음 연구에 참여했을 때는 이 도구들이 모두 낯설었습니다.
그래서 AI 도구의 도움을 받아 가며 Docker 컨테이너를 띄우고, 학습·평가 명령을 직접 실행하는 것부터 시작했습니다.
이후에는 하이퍼파라미터와 경로 같은 설정값을 바꿔 가며 다시 실험하고, AUC와 오탐률(FAR) 같은 결과를 비교해 정리했습니다.
결과가 왜 달라지는지 이해하기 위해 코드를 읽으며 파일별 역할과 데이터가 흐르는 순서를 파악했고, 필요한 부분은 직접 수정해 실험에 반영했습니다.

모델에 대한 이해는 논문으로 보완하고 있습니다.
CNN, ViT, CLIP 같은 모델의 논문을 읽고 정리하면서, 실험 코드 속 구조가 어떤 아이디어에서 나왔는지 연결해 보고 있습니다.
